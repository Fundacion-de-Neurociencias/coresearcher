## 2. Range equivalence (z3)

Each theorem is "for every parameter in a range R, a conclusion holds", so its strength grows with R. The paper's
hypothesis range and the Lean range are written as predicates over the parameters (`n` an integer ≥ 2, the rest
reals) and z3 decides whether they are the same set. **STRONGER** means the Lean range strictly contains the paper's,
**WEAKER** that it is strictly contained in it. Ranges with `max`, `min` and `abs` are rewritten into exact case
splits; `n` is a z3 `Int`, so the answers hold for every dimension, not a sample. No query timed out (solver timeout
10 s per call, threshold `solver_timeout_ms`), so no row is UNDECIDED. Each row was also re-decided through
`HypothesisEvaluator.compare` with `n ∈ {2, …, 6}`, and both answers agree.

Encodings of the Lean types (all recorded per row in the report):

- `p : ℝ≥0∞` with `1 ≤ p` (Bochner–Riesz) becomes `q = (p⁻¹).toReal ∈ [0, 1]`, a bijection with `p = ∞ ↦ q = 0`.
  The `toReal` here is not a junk value, because `1 ≤ p` keeps `p⁻¹` finite (lint, line 101).
- `a : ℝ≥0∞` with `1 < a` (restriction) becomes `q = 1/a ∈ [0, 1)`. Lean's `conjugateExponent` is encoded branch by
  branch: `if a = ∞` is `q = 0`, the else branch uses `a.toReal = 1/q`.
- A real `p` or `b` in Lean is finite, which is the paper's `p < ∞`, `b < ∞`.

Two rows connect the range check with the junk-value lint:

- **Non-strict δ.** At `δ = 0`, `Real.rpow 0 0 = 1` makes `bochnerRieszSymbol` equal to 1 everywhere, so
  `bochnerRiesz 0 R` is the identity and the bound holds trivially. The witness (n = 2, p = 4/3, δ = 0) is a point where
  the paper's operator would be the ball multiplier, which is unbounded there (Fefferman). The real statement's strict
  `max(…, 0) < δ` keeps that junk value out; the lint records it as discharged (line 49).
- **Unguarded `toReal`.** Without `if a = ∞`, `ENNReal.toReal ∞ = 0` would give a conjugate exponent 0 at `a = ∞`. The
  range does not change, because `b > 2n/(n-1)` already exceeds `(n+1)/(n-1)`. The guard is correct but redundant for
  the range; z3 shows that a junk value can be masked by another hypothesis.

Reviews of the open findings (CoResearcher agent analysis, not machine-checked; a human should confirm):

1. **`‖ξ‖ / R` in `stein_square`.** Not a fidelity gap. `bochnerRieszSymbol` is used with `R := s`, the variable of
   the `deriv` lambda evaluated at `r ∈ Ioi 0`, so the division is only needed for `s` near `r > 0`.
2. **`^ δ` in `stein_square`.** Not a fidelity gap. The exponent is the order `α`, and the premise gives
   `α > max(1/2, …) ≥ 1/2 > 0`, so `0 ^ α = 0`.
3. **`deriv` in `literalSteinSquareFunction`. Open question for a human, believed harmless.** `deriv` is 0 wherever
   `r ↦ B_r^α f(x)` is not differentiable, which would shrink the square function and weaken the statement. For Schwartz
   `f`, polar coordinates and `ρ = r t` give `B_r^α f(x) = c rⁿ ∫₀¹ (1 - t²)^α t^(n-1) F_x(r t) dt` with `F_x` smooth,
   which is smooth in `r > 0` for every `α > -1`. So for `α > 1/2` the junk branch should never fire. The statement
   itself has no differentiability conjunct, and nothing here checks the argument. Its definition otherwise matches
   the paper's `G_α f(x) = (∫₀^∞ |r ∂_r B_r^α f(x)|² dr/r)^{1/2}` (Section 11).

Discharges by "Schwartz data" are the lint's weakest rule: they rest on the integrand being the Schwartz datum (or its
Fourier transform) times a symbol of at most polynomial growth. That holds for the Bessel, half-wave and Bochner–Riesz
symbols here, and a reviewer should still read them.

|---|---|---|---|---|

For Theorem 1.2 the Lean bound uses `(1 + log(1/h))^(2n+5)` with `h = 1/N ≤ 1`; that factor and `log(2 + N)` are
comparable, so the powers compare directly. For the Kakeya maximal bound, `[log(2/δ)]^{4/pc} ≤ C_ε δ^{-ε}` for every
`ε > 0`, so the paper's estimate implies Lean's; the converse fails, since Lean allows a polynomial loss. This
comparison involves logarithms and real powers, which are outside the decidable fragment, so it is argued here and not
decided by z3.

Smaller observations that are not range questions:

- `bochner_riesz` quantifies over Schwartz `f`; the paper states (10.1) on Lᵖ. For `p < ∞` density closes the gap. At
  `p = ∞`, Schwartz functions are not dense, but for a convolution operator with an L¹ kernel the operator norm on
  Schwartz data already equals the kernel's L¹ norm, so the bound is the same.
- `spherical_restriction` quantifies over `g` with `MemLp g a (sphereMeasure n)`, and `sphereMeasure` is Mathlib's
  `toSphere` pushed to ambient space. A constant factor between it and the paper's surface measure is absorbed by `∃ C`.
- `kakeya` assumes no measurability, which is at least as strong as the paper's statement.

## 7. Limits

- The range encodings are written by hand from the paper and the Lean text. z3 decides the encodings, not the
  transcription; the transcriptions are quoted next to each row so a reader can check them.
- The lint is syntactic. It does not elaborate Lean, so it can miss junk values hidden behind Mathlib definitions
  (it sees `eLpNorm`, not the `ENNReal` arithmetic inside it), and its discharges name the text they rely on rather
  than proving anything.
- Conclusions (the inequality each theorem asserts) are compared only where they reduce to exponent ranges. The objects
  themselves (Fourier conventions, the half-wave, the observation measure on `[1, 2]`, the tube, `G_α`) were compared by
  reading: they match the paper's definitions (Section 1.3 convention `f̂(ξ) = ∫ e^{-iX·ξ} f`, inverse factor
  `(2π)^{-n}`).
