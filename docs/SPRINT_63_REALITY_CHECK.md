## 4. Phases

### PHASE 1 — Historical Benchmark

Build a collection of historical cases where they are known to have existed
shared constraints (scientific revolutions).

For each case:
- Dominant paradigm
- Persistent assumptions
- What was questioned
- What changed
- What remained

Question: Does the notion of "shared constraint" correctly describe these cases?

### PHASE 2 — Negative Controls

Look for cases where many trajectories converge but do NOT exist
a common restriction.

Examples: technological fads, accidental dependencies, network effects, lock-in.

Question: Can convergence appear without restriction?

If yes → convergence ≠ sufficient evidence.

### PHASE 3 — Alternative Explanations

For each observed convergence, generate hypotheses ALWAYS including:

```text
"There is no shared restriction"
```

as a mandatory competing hypothesis.

Never allow a single explanation.

### PHASE 4 — Operational Stress Test

Take the 12 hypotheses from SPRINT 62 and ask independent reviewers
that they evaluate: observable? measurable? predictions? counterfactuals?

Measure agreement. If κ ≈ 0 → the variable is poorly defined.

### PHASE 5 — Exit Criteria

Only three results:

- **GREEN**: The variable shows inter-reviewer stability and predictive power
- **YELLOW**: The variable needs refinement
- **RED**: Variable is not stable → abandon "shared constraint"

No emotional attachment.
