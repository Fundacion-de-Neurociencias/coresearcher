# Human-Agent Interaction Levels
## From Rider to Passenger Models

---

## The Transition is already happening

Today AI in science is presented as:

```
Humano vs IA
```

But the real model is:

```
Humano + 3-5 agentes
```

without calling it that.

---

## The 3 Levels of Interaction

### Level 1: Agent-in-the-loop
```
Investigador trabaja
↓
Agente ayuda
```

Current model.

---

### Level 2: Human-in-the-loop
```
Agentes trabajan
↓
Humano supervisa
```

Model in transition.

---

### Level 3: Human-on-the-loop
```
Agentes trabajan
↓
Humano recibe alertas
↓
Intervención selectiva
```

Future model.

---

## Alerts that Matter

Only humans intervene when:

```
High uncertainty detected
↑
Trust score < threshold

Novelty score > threshold
↑
Potential discovery

Major contradiction detected
↑
Conflict resolution needed

Ethics flag
↑
Escalate review

Commercial value detected
↑
IP decision needed

Strategic decision point
↑
Research direction
```

---

## Decision as Main Asset

Agents can generate thousands of documents.

What is scarce are:

```
Decisiones humanas
```

### Types of Decisions
- Approve publication
- Reject publication
- Request replication
- Keep private
- File patent
- Escalate ethics review
-Open collaboration

---

## Two User Profiles

### Rider (Full Control)
```
Investigador + Escuadrón de agentes
```
- Detailed control
- Frequent intervention
- Advanced users

### Passenger (Autopilot)
```
Investigador + Piloto automático
```
- Only intervenes when necessary
- Automatic alerts
- Majority of users

## Architecture Implication

You should not coordinate only agents.

You must decide **when not to disturb the human**.

That smart scaling:
- It is more valuable than mechanisms
- It is more valuable than discovery engines
- It is the true competitive advantage
