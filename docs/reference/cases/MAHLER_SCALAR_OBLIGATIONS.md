## 1. Why this input

The released reasoning summary for family 087 (Mahler, Part III) ends with a proof that is conditional on uniform
scalar inequalities. The manuscript "The Mahler Conjecture for General Convex Bodies" (openai/math, commit
`7ef5c0cc`) collects these inequalities in one place. They are Lemma *Profile identities* and Proposition *Scalar
inequalities*, `prop:scalar-input` in `build/sections/01-cones.tex`. The inequalities involve fixed one-variable
profiles built from the Gaussian distribution function, and fixed parameters that do not depend on the body or the
dimension. The parameters (b = .602, c = .365, r = .22, s = 3.6, …) are the same as in the summary.

The current formal and computational coverage of this input is as follows:

- **Lean.** Family 087's Lean targets cover only the symmetric case and its equality classification
  (`symmetric_mahler`, `symmetric_mahler_equality`). The general case is not formalized.
- **Author certificates.** Appendices 7–8, plus ten Python programs in `verification/` (interval enclosures and
  Bernstein bounds).
- **Our checks.** We did not run those programs. Under ADR-076 they are read as data and not executed. Our checks
  below are re-implemented from the statements.

## 2. Ledger

The scalar input has 20 obligations. Each inequality that we proved on a bounded window is split in two: the window
part, which we prove, and the rest of its domain, which we do not. A window proof never discharges the statement for
all x (ADR-076). Values come from `ledger.json` and `interval_proof.json`.

| Obligation | Status | Margin | Scope |
|---|---|---|---|
| Identities (N+2)g = d; d′ = 2xd − v′ − 2g′; Nd − v″ = −(N+2)(d + g″) | **DISCHARGED_SYMBOLIC** | exact | any p with p′ = φ |
| The 7 first-bullet inequalities, on \|x\| ≤ 8 | **DISCHARGED_INTERVAL** | certified lower bounds > 0 on 4,644 boxes | \|x\| ≤ 8 |
| The same 7, for \|x\| > 8 | CHECKED_NUMERIC + CERTIFIED_BY_AUTHOR | sampled margins as below | numeric: 8 < \|x\| ≤ 20; authors: all x |
| The 2 inequalities (3), on [−3, 3]² | **DISCHARGED_INTERVAL** | certified lower bounds > 0 on 167,121 box pairs | (z, x) ∈ [−3, 3]² |
| The same 2, outside [−3, 3]² | CHECKED_NUMERIC + CERTIFIED_BY_AUTHOR | ≈ 0.024 and ≈ 1.0 (sampled) | numeric: [−12, 12]²; authors: all |
| (4), the segment inequality | CHECKED_NUMERIC + CERTIFIED_BY_AUTHOR | ratio of the two sides ≤ 0.73 (sampled) | segments in [−12, 12] |

The sampled margins (high precision, grid 0.02) of the first bullet are:

| Inequality | Smallest sampled margin |
|---|---|
| b − r² − d > 0 | ≈ 0.055 (at x = ±20) |
| \|v′ − x\| ≤ .319 | ≈ 0.001 |
| C ≤ −.341 | ≈ 3.4·10⁻⁴ (at x = 0) |
| S_q > 0 | ≈ 0.116 (at x = 0) |
| λt₋² + t₋C + K > 0 | ≈ 9·10⁻⁴ |
| λt₊² + t₊C + K < 0 | ≈ 7.5·10⁻⁴ |
| 2(−.37)C − .37² − 4λK > m*² | ≈ 0.009 |

**Claim status: CHECKED_NUMERIC. It is not a proof of the whole proposition.** What CoResearcher has proved,
independently of the authors' code:

1. the three profile identities (exactly);
2. all seven first-bullet inequalities on |x| ≤ 8;
3. both two-variable inequalities (3) on [−3, 3]².

The parts that we did not prove are the tails (|x| > 8, and outside [−3, 3]² for (3)) and the segment inequality
(4), which involves averages over segments. They rest on our sampled evidence plus the authors' appendices and
programs.

The tight spots are the ones the sampling found, and the interval proof certifies them: C ≤ −.341 near x = 0, and
the quadratic conditions near x ≈ 0 and x ≈ 3.4. Negative controls show that tightening a constant (C ≤ −.342,
|v′ − x| ≤ .317) makes both the sampling and the interval proof fail.

## 3. Method notes

- **Precision.** The profile X = p/φ grows like e^{x²/2} and multiplies quantities of size e^{−x²}. Evaluation
  therefore uses 60 + 0.9x² decimal digits, and 1 − p is computed as erfc(x/√2)/2 rather than by subtraction. A
  first attempt at fixed precision produced values of order 10⁴⁰, which come from the arithmetic and not from the
  profiles.
- **Derivatives.** They are exact symbolic derivatives (SymPy), evaluated in mpmath. Segment averages use the
  trapezoid rule on the 0.02 grid.
- **Encoding check.** The identities first failed because p and 1 − p had been encoded as independent functions. They
  are proved once 1 − p is substituted back. That was an encoding error on our side, not a defect of the paper.

## 4. How the interval proof works

Details are in the docstring of `mahler_interval.py`.

1. **Stable forms on x ≥ 0.** With Y = (1 − p)/φ (the Mills ratio), u = 1 − p = φY and
   h₀(y) = (−log(1 − y) − y)/y² = Σ y^m/(m + 2), the profiles become

   - d = (φ + xp)² Y² h₀(u) + (1 − xY)² j,
   - g = (1 − p²Y²h₀(u) − Y²j)/2,
   - v = log p + log Y + x²/2 + log √(2π),

   with j = −1 + u + x²/2 + log √(2π) − log Y. They contain no exponentially large factor. Derivatives close over
   p′ = φ, φ′ = −xφ, Y′ = xY − 1, u′ = −φ and h_k′ = −φ h_{k+1}. SymPy proves four things:

   - these forms equal the paper's profiles;
   - d, g and v are even (x ↦ −x swaps p and 1 − p), so x ≥ 0 suffices;
   - the derivative rules;
   - the three identities.
2. **Rigorous inputs.** At a point, p and 1 − p come from the alternating erf series, with its remainder bound,
   in interval arithmetic. On a box, monotonicity gives the enclosures: p increases; φ, Y (= ∫₀^∞ e^{−xt−t²/2} dt)
   and u decrease; h_k has positive coefficients.
3. **Enclosures and branch and bound.** The first bullet uses the mean-value form f(m) + f′(box)·[−w/2, w/2]. The
   one-variable pieces of (3) use second-order Taylor forms, combined over box pairs in float intervals widened by
   one ulp per operation, with every constant enclosed exactly. A box is certified when every margin's lower bound
   is positive; otherwise it is bisected. Symmetry (z, x) ↦ (−z, −x) halves the two-variable domain.
4. **Trust base.** The proof relies on the correctness of mpmath's interval arithmetic (outward rounding) and of
   IEEE-754 round-to-nearest for the float stage. It does not use the authors' programs.

## 5. What remains

- **Tails.** Beyond |x| ≈ 3–8, naive interval evaluation of high derivatives loses the asymptotic cancellations, and
  boxes would need to be tiny. Proving the tails needs an asymptotic representation, which is what the authors'
  appendix does.
- **The segment inequality (4).** It needs rigorous enclosures of averages over segments, which is integral
  arithmetic. This is not done here.
- **The rest of the proof.** The cone, entropy and quadratic arguments of Sections 1–6 are outside this ledger.
  They are covered by the manuscript alone. A Lean formalization is the route to checking them.
