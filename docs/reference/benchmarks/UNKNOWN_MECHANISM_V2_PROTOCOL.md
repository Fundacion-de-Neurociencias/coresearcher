# Unknown-mechanism benchmark v2: pre-registered protocol

Status: written before the first run of the v2 script. The SHA-256 of this file is printed and stored
with every result, so any later edit to the protocol is detectable.

## 1. Question

When a mechanism is selected from a generic hypothesis library using only a validation split, does the
selected model predict held-out data better than (a) a naive linear model and (b) an unselected flexible
regression, and how often does it select the family that matches the hidden law?

This replaces the v1 protocol. The v1 scoring selected mechanisms on the test split, used a library that
contained the true law, and computed relative gains against a near-zero baseline. See section 9.

## 2. Worlds

- 100 worlds, world `i` in `0..99`, archetype `ARCHETYPES[i mod 6]` (17 or 16 worlds per archetype).
- Data generated by the existing `UnknownMechanismBenchmark.generate_world` formulas, seed `1000 + i`,
  with `n = 240` rows. Its first half is split into **discovery** (rows 0-59) and **validation** (rows 60-119).
  The second half is the **test** split (120 rows). The test split is read only in the final evaluation step.
- Observed variables: `X`, `Z_1`, `Z_2`, and 20 background variables. The archetype is never given to the
  procedure.

## 3. Hypothesis library (fixed)

Each candidate is a linear model refit on the discovery split. Features are fixed before the run.

| Family | Features | Candidates |
| --- | --- | --- |
| `naive_linear` | 1, X | 1 |
| `interaction_Z1` | 1, X, Z_1, X·Z_1 | 1 |
| `interaction_Z2` | 1, X, Z_2, X·Z_2 | 1 |
| `quadratic_X` | 1, X, X² | 1 |
| `additive_basis` | 1, X, Z_1, Z_1², sin(ωX) | 4 (ω ∈ {0.4, 0.8, 1.2, 1.6}) |
| `regime_Z1` | 1, X, I(Z_1 > t₁), X·I(Z_1 > t₁), with t₁ = median of Z_1 on discovery | 1 |
| `regime_Z2` | same as above with Z_2 and t₂ = median of Z_2 on discovery | 1 |
| `latent_pc1` | 1, X, PC1 of the background variables (PCA fitted on discovery) | 1 |

Thresholds and PCA components are estimated on the discovery split only.

## 4. Procedure

1. Fit every candidate on the discovery split. Score each on the validation split by R².
2. Select the candidate with the highest validation R². Ties go to the candidate with fewer parameters.
3. Refit the selected candidate on discovery ∪ validation (120 rows). Evaluate on the test split once.
4. Baselines, refit on discovery ∪ validation and evaluated on test:
   - **naive**: the `naive_linear` family.
   - **flexible**: unselected degree-3 polynomial in (X, Z_1, Z_2), with 13 terms and no selection.

## 5. Metrics

- Test R² for the selected model (`R2_abduced`), the naive baseline (`R2_naive`) and the flexible baseline
  (`R2_flex`). R² is **not** clipped at zero.
- Per-world differences: `ΔR²_naive = R2_abduced − R2_naive` and `ΔR²_flex = R2_abduced − R2_flex`.
  Absolute differences only. No relative gains.
- Recovery: the selected candidate's family equals the expected family in the mapping below.

| Archetype | Expected family |
| --- | --- |
| HARMONIC_NONLINEAR | additive_basis |
| MULTIPLICATIVE_COUPLING | interaction_Z1 |
| UNOBSERVED_LATENT_MANIFOLD | latent_pc1 |
| REGIME_PHASE_SHIFT | regime_Z1 |
| SIMPSONS_CAUSAL_INVERSION | regime_Z2 |
| THRESHOLD_INVARIANT_GATE | none (no library family can express it) |

THRESHOLD_INVARIANT_GATE is excluded from the recovery denominator. It is reported separately as a
known gap of the library.

## 6. Uncertainty

- Proportions (recovery, fraction of worlds with ΔR² > 0): 95% Wilson intervals.
- Mean differences: 95% percentile intervals from a paired bootstrap over worlds, 10,000 resamples,
  seed `20261012`.

## 7. Pre-registered success criteria

- **Primary:** the lower bound of the 95% bootstrap interval for mean `ΔR²_flex` is greater than 0.
  Selection must beat an unselected flexible regression on held-out data.
- **Secondary:** the lower bound of the Wilson interval for recovery (excluding THRESHOLD_INVARIANT_GATE)
  is greater than 1/4, the chance rate among the four families that can be selected for the archetype
  mapping. This is an arbitrary but fixed reference, not a claim about the scientific meaning of recovery.

A criterion that is not met is reported as not met. The script does not change thresholds after seeing results.

## 8. Known limitations (stated in advance)

- The worlds are synthetic. Results describe behaviour on these generating laws, not on research data.
- The library is generic, but it contains the functional forms used by the generator, so recovery is
  possible by construction for some archetypes. This is why the flexible baseline is required.
- Samples are small (60 discovery, 60 validation, 120 test rows).

## 9. Defects in v1 that v2 corrects

1. Mechanism selection used the test split (`candidates.sort` by holdout R²), so reported holdout R² was optimistic.
2. The candidate library contained the exact true expression for HARMONIC_NONLINEAR (`sin(0.8X) + 0.15Z²`).
3. Relative gain divided by `max(naive_R², 1e-4)`. A naive R² close to zero produced gains above 30,000%.
4. Recovery was counted as true when the holdout R² reached 0.70, which made the criterion depend on the same
   test split that was used for selection.

## 10. Post-hoc additions and outcome (recorded after the primary run)

- The primary run (`unknown_mechanism_v2_results.json`) met both pre-registered criteria. Its
  per-archetype breakdown then showed that the aggregate depends on two archetypes that the library can express
  by construction, and that the UNOBSERVED_LATENT_MANIFOLD "recoveries" have test R² close to zero.
- A **null control** was added after that run: Y is permuted within each world (seed `7000 + i`) and the same
  procedure runs unchanged (`--null-control`). It is stored in a separate file. The pre-registered thresholds
  were not changed.
- Null-control outcome: recovery 13/84 (15.5%), mean ΔR² vs flexible +0.077 (bootstrap 95% +0.061 to +0.093),
  mean ΔR² vs naive -0.038.

**Verdict.** The primary criterion is satisfied on pure noise. Its lower bound is therefore not evidence
that selection discovers mechanisms. Its only effect is to show that the unregularised 13-term flexible
baseline overfits 120 rows. The recovery metric separates real data (85.7%) from the null (15.5%), but it is
partly built into the library, so it is not an independent test of discovery.

The v2 result is a **negative methodological finding**: the pre-registered primary criterion does not
discriminate signal from noise. A valid successor needs (i) a flexible baseline tuned by the same
validation procedure, (ii) generating laws absent from the library, and (iii) the null control as a
pre-registered gate.
