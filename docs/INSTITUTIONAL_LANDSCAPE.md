## Detailed Territory Map

### ORCID = Identity Infrastructure
```
Solves: Who am I?
Scope: Researchers, contributors, creators
Limitation: No coordination beyond identity
```

### DOI/Crossref = Artifact Infrastructure  
```
Solves: What exists permanently?
Scope: Published papers, datasets, software
Limitation: Only final artifacts, no process
```

### OSF = Research Lifecycle Infrastructure
```
Solves: How do I manage a project?
Scope: Projects, files, preregistrations, sharing
Limitation: Human-centric, not agent-native
```

### GitHub = Development Infrastructure
```
Solves: How do we version code collaboratively?
Scope: Code, documentation, issues, workflows
Limitation: Not scientific, technical focus
```

### OpenScience = Agent Execution Infrastructure
```
Solves: How do agents execute science?
Scope: Agent sessions, MCP integration, workspace
Limitation: No persistence or coordination layer
```

### CoResearcher = Scientific Activity Infrastructure
```
Solves: How do we record and coordinate scientific activity?
Scope: Questions, Actions, Reviews, Decisions, Artifacts
Unique Value: Immutable ledger of agent-human coordination
```
