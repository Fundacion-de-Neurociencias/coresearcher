## Knowledge Objects (Universal)

| Primitive | Description | Example |
|-----------|-------------|---------|
| **Question** | Inquiry seeking resolution | "What predicts AD before PET?" |
| **Hypothesis** | Testable proposition | "pTau217 + APOE4 improve prediction" |
| **Prediction** | Expected outcome | "AUC > 0.85 in preclinical cohort" |
| **Evidence** | Support/contradiction data | p=0.001, n=1254, proof completed |
| **Claim** | Asserted finding | "Combined biomarkers predict progression" |
| **Trust** | Quality/confidence score | 94/100 weighted assessment |
| **Provenance** | Source/traceability | [HYP-001, PMID-12345, TEST-001] |

## Scientific Cycle (Universal)

```
Question
  ↓
Hypothesis
  ↓
Prediction
  ↓
Test (method varies by domain)
  ↓
Evidence
  ↓
Claim (supports/refutes)
  ↓
Trust (quality assessment)
  ↓
Knowledge Objects persist
```

---

## Domain Examples

### Biomedical Research
```
Question → Hypothesis → Prediction → Experiment → Evidence → Claim
```

### Mathematics
```
Question → Conjecture → Theorem → Proof → Evidence → Claim
```

### Social Sciences
```
Question → Hypothesis → Prediction → Survey → Evidence → Claim
```

### Physics
```
Question → Hypothesis → Prediction → Observation → Evidence → Claim
```

## Knowledge Infrastructure Value

Storing:
- **Question-XXXXX**: What we're trying to understand
- **Hypothesis-XXXXX**: What we believe might be true
- **Prediction-XXXXX**: What we expect to observe
- **Test-XXXXX**: How we test it
- **Evidence-XXXXX**: What we observed
- **Claim-XXXXX**: What we conclude
- **Trust-XXXXX**: How confident we are

This is the scientific process infrastructure - more valuable than knowledge alone.
