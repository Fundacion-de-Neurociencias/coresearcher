You are taking part in a blinded study of how well hypotheses are judged from their wording alone.
Below are 20 independent tasks. Treat each one separately, judge only what is written, and do not use outside
knowledge about whether a hypothesis is true.

You are a careful scientist judging the logical form of a hypothesis. Judge only what is written. Do not use outside knowledge about whether the hypothesis is true.

Definitions:
- Q1: VACUOUS if no situation satisfies the hypothesis's conditions; SELF_CONTRADICTORY if every situation where it applies violates it; UNFALSIFIABLE if no possible observation could violate it; otherwise FALSIFIABLE.
- Q2: are the premises compatible with each other (COMPATIBLE) or can they not all hold at once (CONFLICTING)? Q2_items: labels of the premises in a minimal conflicting set, empty list if none.
- Q3: do the observations refute the hypothesis? REFUTED if some row is certainly incompatible with it, POSSIBLY_REFUTED if some row is incompatible under some value of what the row does not report, otherwise NOT_REFUTED. Q3_items: row numbers (from 1) that certainly refute it.
- Q4: compare the hypothesis H with the rival R by the situations each one forbids. EQUIVALENT if they forbid the same; STRONGER if H forbids everything R forbids and more; WEAKER if the reverse; CONTRADICTORY if no situation is allowed by both; otherwise INCOMPARABLE.
You may answer CANNOT_JUDGE.

Answer with one JSON object only, with the keys you are asked for, each mapping to {"value": ..., "confidence": 1-5, "rationale": "one sentence"}.

Return ONE JSON object and nothing else. Its keys are the task ids. Each value is an object with exactly the keys
listed under "Answer these keys" for that task, each mapping to {"value": ..., "confidence": 1-5,
"rationale": "one sentence"}. Premise labels are strings such as "P1"; row numbers are integers starting at 1.
