## 1. Why this case

Sakana's Agentic Scientist (arXiv:2610.18933) checks its constraints with natural-language rubrics that the agent
grades itself. For Error Diffusion (ED), Table 6 compares three rubrics. Under the loose one the agent reached 0.9694
validation accuracy **without implementing ED**. The intermediate rubric (an explicit ban on backpropagation) gave
0.976 with a correct ED implementation. The strict rubric (no backpropagation, no transport through `W^T`, one global
error sign, polarity invariance) gave 0.9708. Accuracy did not show whether the method had been implemented.

The strict rubric contains a mathematical claim: with four non-negative weight matrices per layer, the sign of each
weight's effect on the output is fixed by stream membership, so one global error sign is enough to update every
weight in the right direction. CoResearcher turns that claim into a decidable object, proves it, and shows which
assumptions it needs. CoResearcher judges the mathematics, not the experiment or the paper's evidence.

## 2. The formal object (ADR-DISCOVERY-059/060)

Network: `p_i = f(p_{i-1} W_pp - n_{i-1} W_np + b_p)`, `n_i = f(n_{i-1} W_nn - p_{i-1} W_pn + b_n)`, output
`y = p_L[0]`, loss `e²/2` with `e = y - target`.

| Part | Content |
| --- | --- |
| Variables (continuous) | every weight, `f'` at every unit (`d`), every sensitivity `s = dy/d(unit)`, every presynaptic activity `x`, the error `e` and `sg` |
| Scope (definitions) | the chain rule: `s^p_L = (1,0,…)`, `s^n_L = 0`, the backward recursion through the four matrices, and `sg = sign(e)` |
| Assumptions | `W_pp ≥ 0`, `W_np ≥ 0`, `W_nn ≥ 0`, `W_pn ≥ 0`, `f'_p ≥ 0`, `f'_n ≥ 0` (six, each droppable) |
| Claim 1: polarity invariance | `s^p_i ≥ 0` and `s^n_i ≤ 0` at every hidden layer |
| Claim 2: sign sufficiency | for every weight, `Δw_ED · ∂L/∂w ≤ 0`, where `Δw_ED = -(σ_post τ_w) · pre · f'(post) · sign(e)` and `∂L/∂w = e · τ_w · pre · f'(post) · s_post` (`σ` = +1 for the p stream, -1 for n; `τ` = -1 for the subtracted matrices `W_np`, `W_pn`) |

Activities and derivatives are free reals, not tied to one `f`. A proof over this larger space holds for every real
network. A counterexample over it could in principle be unrealizable, so each refuted variant was also replayed on a
concrete network.

A proved claim shows up in the court as content verdict `UNFALSIFIABLE` (no state allowed by the definitions and
assumptions violates it), with jointly satisfiable assumptions and a non-empty scope. The module reports it as
`PROVED`. A refuted claim shows up as `FALSIFIABLE`, with a witness state.

## 3. Results

### Proved by z3 (fixed depth L and width W)

| Size | Polarity invariance | Sign sufficiency |
| --- | --- | --- |
| L = 1, 2, 3, 4 with W = 1 | proved (none at L = 1) | proved |
| L = 1, 2, 3 with W = 2 | proved | proved |

The tests re-check the refutation witnesses with the predicate interpreter, independently of z3. L = 5 (W = 1) and L = 3 (W = 2, with
both claims in one call) hit the 10 s solver timeout. The module reports a timeout as `UNDECIDED`, never as a verdict,
and so checks the two claims as separate calls.

### Proved by Lean (any depth, any width)

`EdPolarity.lean` states the same two claims for any depth and any width. Layers are indexed downward from the
output, and `f'` values are arbitrary non-negative reals:

- `sens_polarized`: polarity invariance at every depth, by induction on layers;
- `ed_sign_sufficiency`: for every weight at every depth, the ED update has a non-positive product with the true
  gradient.

The Lean 4 kernel checked it on 2026-10-15 on the Mac Studio (Lean 4.35.0, Mathlib v4.35.0). The check took 5.7 s
and used no `sorry`. `#print axioms` lists only `propext`, `Classical.choice` and `Quot.sound`. The file hash is
recorded in the log, and a test fails if the file changes without a new check.

### Variants: which assumptions are necessary

| Variant | Court verdict | Witness |
| --- | --- | --- |
| Drop all `W ≥ 0` (L = 2, 3) | **refuted** | `W_pp` at the top layer `= -1` gives `s^p_1 = -1`; the ED update for `W_pp` at layer 1 then points uphill |
| Drop `f' ≥ 0` (L = 2, 3) | **refuted** | `f' = -1` at the output unit with all weights `≥ 0` gives `s^p_1 = -1` |
| Transposed-weight path, **sign** (L = 2, 3) | **proved equivalent** | none: under the assumptions, the sign that `W^T` transport would deliver is already fixed by the stream |
| Transposed-weight path, **value** (L = 2, 3): "the ED update is the `W^T`-transported update up to one positive scale", on non-degenerate networks (all `W`, `f' > 0`) | **refuted** | top `W_pp = 0.5`, other weights 1: the gradients of the `W_pp` weights of layers 1 and 2 stand in ratio 0.5, their ED updates in ratio 1 |

The court also finds a dependence on depth that the prose rubric does not state:

| Depth | Assumptions needed (each dropped alone, W = 1 and W = 2) |
| --- | --- |
| L = 1 | none: with no hidden layer, `Δw_ED · ∂L/∂w = -|e| · pre² · f'² · …` is non-positive for any signs |
| L = 2 | only `W_pp ≥ 0`, `W_np ≥ 0`, `f'_p ≥ 0` (the n-stream output has no effect on `y`, so `W_nn`, `W_pn` and `f'_n` do not matter yet) |
| L ≥ 3 (checked at 3 and 4) | all six |

Two assumptions are not needed at any depth: presynaptic activities need not be non-negative, because `pre` enters
both the gradient and the ED update; and the learning rate only needs to be positive.

### Replay on concrete networks (independent of the solver)

Finite differences of `y` with respect to every weight, compared with the sign that ED assigns:

- 50 random networks (L = 3, W = 2, sigmoid, weights in [0, 2]): 2,400 weights, **0 disagreements**;
- the `W ≥ 0` witness as a sigmoid network (top `W_pp = -1`): 2 of 8 weights get the wrong sign;
- the `f' ≥ 0` witness as an `f(z) = z²` network with every weight `≥ 0` and a negative top pre-activation: 4 of 8
  weights get the wrong sign.

## 4. What this shows

1. **The rubric's claim is true, and the court can say why.** With the six assumptions, polarity invariance and the
   sufficiency of one global error sign hold at every depth (Lean). Small sizes are also covered by z3.
2. **Every assumption is needed somewhere, but not everywhere.** A rubric that says "weights non-negative" without
   `f' ≥ 0` describes a method that fails from depth 2 on, as soon as `f' < 0` at some unit above a hidden unit (for example `f(z) = z²`). The court names the
   missing auxiliary and gives a network where it matters.
3. **Sign checks cannot detect a `W^T` backward path.** Under the Dale constraint, backpropagation through `W^T` and
   ED's broadcast give updates of the same sign on every weight; they differ only in magnitude. A grader that checks
   signs or polarity will pass a backprop implementation. To detect weight transport, it must check magnitudes or
   the information flow. This is consistent with Table 6, where an agent reached similar accuracy without
   implementing ED.
4. **The role CoResearcher plays.** In an agentic-science pipeline, the rubric's natural-language constraint becomes a
   formal hypothesis with explicit assumptions. The court answers with proofs, counterexamples and the necessity of
   each assumption, never with a self-assigned score.

## 5. Limits

- The formal object abstracts `f` to its derivative values at each unit. The Lean theorem covers every such
  assignment, which includes every real network with `f' ≥ 0`.
- The claim is about the single-output case `y = p_L[0]`. Multi-output ED with per-output error signs is not covered.
- The court proves sign agreement per weight. It says nothing about convergence, speed or accuracy of ED training,
  which are empirical questions outside CoResearcher's scope.
- The rubric text was taken from the paper's main text and Table 6. The authors' exact G.4 wording may differ.
